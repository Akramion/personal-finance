# Product idea

Personal finance assistant for one user.

Main problems:
- user has income once or several times per month
- user has debts and credit cards
- user wants to understand how much money is safe to spend
- user wants to plan debt repayment
- user wants to track categories and monthly limits

MVP:
1. Add accounts
2. Add debts
3. Add income
4. Add expenses
5. Calculate current balance
6. Calculate required monthly payments
7. Calculate free money until next payday
8. Show simple debt payoff plan

Not in MVP:
- bank integrations
- real payments
- multi-user auth
- mobile app
- complex analytics
